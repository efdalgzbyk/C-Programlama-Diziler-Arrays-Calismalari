## 📌 Diziler Nedir?

Diziler, aynı türden birden fazla veriyi tek isim altında tutan yapılardır.  
Bellekte **ardışık** olarak tutulurlar ve elemanlara **indeks** ile ulaşılır.  
İlk elemanın indeksi her zaman **0**'dır.

Örnek:

```c
int A[5];  // 5 elemanlı integer dizi
// Elemanlar: A[0], A[1], A[2], A[3], A[4]
